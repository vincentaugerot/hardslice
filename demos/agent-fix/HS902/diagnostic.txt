HS902: 'Room' is mapped as an EF Core entity by 'RoomConfiguration' but implements neither 'IEntity' nor 'IAggregateRoot'. HardSlice classifies domain types only through these contracts. Fix: implement IAggregateRoot if 'Room' is the root of its aggregate, IEntity otherwise, or, if 'Room' is a value object, remove 'RoomConfiguration' or map it with ComplexProperty in its entity. Skill: add-aggregate. Doc: 'docs/rules/HS902.md'.
